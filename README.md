I am excited to share my latest Data Analytics project: **Sales Data Analysis using Python**.

In this project, I performed Exploratory Data Analysis (EDA) to understand customer purchasing behavior, sales performance, product categories, customer demographics, and regional sales patterns.

The main objective was to transform raw sales data into meaningful insights that can support better business decisions.

### 🛠️ Tools & Technologies Used

- Python
- Pandas – Data manipulation and analysis
- NumPy – Numerical operations
- Matplotlib – Data visualization
- Seaborn – Statistical visualization
- Jupyter Notebook – Development environment

### 📊 Project Workflow

**1. Data Loading & Exploration**

- Imported the CSV dataset using Pandas.
- Examined dataset dimensions and column names.
- Checked data types and statistical summaries.
- Identified data quality issues.

**2. Data Cleaning & Preprocessing**

- Removed completely blank rows.
- Removed the empty Zipcode column.
- Standardized Gender values (M/F into Male/Female).
- Cleaned text columns and unnecessary whitespace.
- Corrected data types.
- Checked missing values and duplicate records.

**3. Exploratory Data Analysis – 13 Analysis Tasks**

I performed the following analyses:

1. Gender-wise transaction count.
2. Gender-wise customer distribution.
3. Gender-wise total sales amount.
4. Age group-wise transaction count.
5. Age group-wise total sales.
6. Top 5 states by total quantity ordered.
7. Top 5 states by total sales amount.
8. Product category-wise transaction count.
9. Product category-wise total sales amount.
10. Product category and gender-wise sales analysis.
11. Profession-wise transaction count.
12. Top 5 professions by sales amount.
13. Top 10 products by total quantity ordered.
